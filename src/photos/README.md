# Фото для перелётов

Положи фото в папку страны — игра покажет их после соответствующего уровня:

- `serbia/` — после офиса
- `georgia/` — после холла
- `turkey/` — после улицы, перед финальным поздравлением

Форматы: JPG, PNG, WebP (HEIC с iPhone не поддерживается — экспортируй в JPG).
Порядок — по имени файла. Имя файла становится подписью («Белград.jpg» → «Белград»),
а камерные имена вроде `IMG_1234.jpg` и имена по папке (`serbia.png`) подписываются названием страны.
Если папка пустая, показывается нарисованная открытка.
