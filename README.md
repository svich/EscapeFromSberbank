# Побег из Сбербанка

Помоги девушке сбежать с работы в Сбербанке: раннер на Phaser 4 с векторной чиби-графикой, нарисованной в коде.

Играть: https://svich.github.io/EscapeFromSberbank/

## Запуск

```bash
npm install
npm run dev
```

Игра: http://localhost:5173, превью графики: http://localhost:5173/art.html

## Как играть

Три уровня: офис Сбера, служебное хранилище и зимний Челябинск. На каждом нужно собрать цель по монетам — тогда героиня улетает в следующую страну, а после третьего уровня уезжает на такси на свободу.
Кофе (не больше двух на уровень) на 5 секунд даёт сносить всё на пути. Шоколадка — вторая жизнь.

## Управление

- Пробел (или тап) — прыжок, ещё раз в воздухе — двойной прыжок
- Клик мышью (на телефоне — кнопка с камерой) — вспышка телефона: ослепляет громилу в красной куртке
- `?level=3` в адресе — начать сразу с нужного уровня

## Где что лежит

- `src/art/vector/` — вся графика (герой, препятствия, фоны)
- `src/config.js` — настройки геймплея
- `src/scenes/` — сцены Phaser, `src/audio/` — чиптюн-музыка и звуки
